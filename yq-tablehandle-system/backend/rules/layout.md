# 服务边界

每个服务放在 `app/<服务名>/`。`api` 定义对外契约，`boot` 放进程入口，`internal` 放私有实现，`manifest` 放配置示例，`resource` 放静态资源，`test/testdata` 放测试样本。单元测试与被测包放在一起。

公共包放在根 `utility`，不得反向导入 `app`。共享构建目标放在根 `hack`，服务自己的构建参数放在服务内的 `hack`。各服务共享根 `go.mod`。

管理端接口按 `api/admin/<模块>/<模块>.go` 声明版本接口，`api/admin/<模块>/v1/` 放对应的请求、响应契约。同一模块的相关操作共享版本目录，不为每个 HTTP 路径单建模块。
